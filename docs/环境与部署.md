## 一、现场环境（2026-11 核实）

| 项 | 值 |
|---|---|
| Ubuntu | Linux 6.8.0-149-generic，主机 IP 172.20.10.2 |
| HoloLens2 | IP 172.20.10.3（UDP 直连，端口 5005，协议 rml63.hand_pose.v1） |
| ROS2 | Humble（`/opt/ros/humble`） |
| 机器人工作区 | `/home/dys/DYS_ws`（官方 SDK 源码 `/home/dys/DYS_ws/src/ros2_rm_robot-humble`） |
| Python | 系统 3.10（接收/转换/控制/单次运动/Dora 录制）；miniconda `lerobot` 环境 3.12（verify_dataset） |
| Dora-rs | ≥0.5（系统 Python：`pip install --user 'dora-rs>=0.5.0'`） |
| LeRobot | 0.6.2（本项目 `lerobot/` 副本；官方仓库 huggingface/lerobot，Apache-2.0） |
| 官方 rm_driver 配置 | `rm_63_config.yaml`：arm_ip 192.168.1.18（控制器 TCP），udp_ip 192.168.1.100（控制器 UDP 上报目标），udp_cycle 5ms，udp_joint_speed_state true |

**地址用途说明**：172.20.10.2/…3 为头显↔Ubuntu 直连链路；192.168.1.18 为控制器 TCP
（rm_driver 连接）；192.168.1.100 为控制器 UDP 上报目标 IP（机械臂→上位机）。仓库内
程序将 IP/端口全部做成命令行参数（--bind/--port/--peer），不使用硬编码修改现场配置。

## 二、第三方 SDK：只记录来源，不收录原件

- **官方 SDK `ros2_rm_robot-humble`**：源码与编译库（libapi_cpp.so，v1.1.3）位于
  `/home/dys/DYS_ws/src/ros2_rm_robot-humble/`。`rm_driver/package.xml` 中
  `<license>TODO: License declaration`——无明确许可声明，**不确定能否公开再分发，
  故本仓库不收录原件**。使用时按其 README/README_CN 自行构建：
  ```bash
  cd /home/dys/DYS_ws
  colcon build --packages-select rm_ros_interfaces rm_driver
  source /home/dys/DYS_ws/install/setup.bash
  ```
  接口速查（与仓库代码直接相关）：
  - 订阅 `/rm_driver/movel_cmd`（rm_ros_interfaces/Movel：pose/speed(1..100%)/
    trajectory_connect/block）；block=1 多线程模式阻塞至到达或失败，返回 -6 = 被外部停止中断。
  - 订阅 `/rm_driver/move_stop_cmd`（std_msgs/Empty）→ 发布 `/rm_driver/move_stop_result`（Bool）。
  - 发布 `/rm_driver/udp_arm_position`（Pose）、`/rm_driver/udp_joint_speed`
    （Jointspeed，float32[]，单位 RPM、精度 0.02 RPM）、`joint_states` 等，约 200 Hz。
  - 回调：MultiThreadedExecutor 8 线程；movel 与 stop 在**不同** MutuallyExclusive 回调组
    （阻塞中的 movel 不阻塞 stop）。
- **LeRobot**：Apache-2.0（可再分发，需保留许可声明）；本仓库仅收录自研 RML63 适配器
  （lerobot/src/lerobot/robots/rml63/）。`verify_dataset.py` 需要完整 LeRobot 0.6.2 源码
  置于本项目 `lerobot/src/`（或按官方安装），conda 环境名 `lerobot`。

## 三、离线依赖检查（整理后仓库复测结果）

- 纯标准库脚本（receiver/converter/校准/rewrite）：无需第三方依赖。
- `numpy 1.21.5`、`yaml` 在系统 Python 可用（`--help` 与测试验证通过）。
- `dora-rs`、ROS2、`rm_ros_interfaces`、LeRobot conda 环境：**本轮未验证**
  （不重装环境、不启动驱动）；相关入口（record_dora、replay_dora 的实际 dora.run、
  verify_dataset 的 conda 运行、robot_control 的 ROS 运行）在整理后仓库**未实机复跑**，
  仅做语法检查与 --help 检查（--help 不连接设备、不初始化运动，见脚本 docstring）。

## 四、复现说明（尽力而为，不承诺一键）

1. 依赖项按上表现场版本自行安装（ROS2 Humble、dora-rs、LeRobot 0.6.2）。
2. 官方 SDK 按第二节构建；本仓库不提供 SDK 原件。
3. 离线测试在任何 Linux Python 3.10 下运行：
   ```bash
   python3 -m unittest discover -s tests
   ```
4. 含真实数据用例的测试依赖 `datasets/hololens_checks/run_20261112_101842/`（已收录）。
5. 未收录/未验证项见 `docs/文件清单.md` 第七节与本文件第三节。
