# 单次手控 v2

复制 hololens_hand_step_v2.py 到 Ubuntu 桌面。不覆盖旧程序，不用修改 Unity。
比例为1:1，只取手向上的 Unity Y 位移映射到 Base +Z，姿态不变。
本版每次启动只发送一个目标，不是连续跟随；不会自动重复、返回或恢复。
预览上限5厘米。实机上限仍为5毫米，尚未完成正常到位验证，不能将预览等同实机验收。

保留正在运行的 rm_driver 终端。关闭其他头显UDP接收/预览/控制脚本，释放5005。
在新终端执行：

```bash
source /opt/ros/humble/setup.bash
source /home/dys/DYS_ws/install/setup.bash
python3 ~/桌面/hololens_hand_step_v2.py --enable-motion
```

先确认工具向上有空间、现场急停可用。右手张开1秒，再捏合。
等“手已锚定”，手缓慢上移几毫米，停住半秒，继续捏合等“完成”。
松手请求停止，不等于立即物理停止。停止/错误后不自动恢复，不连续重跑累计位移。
出现中断后保存完整输出和驱动错误码。

只预览5厘米（不发运动指令）：

```bash
python3 ~/桌面/hololens_hand_step_v2.py --max-offset 0.05
```

程序分别记录松开手势、追踪不可用、数据间隔达到200ms等原因，保存首次中断原因。
日志仍写入 Ubuntu 原项目 datasets/hololens_checks/hand_step_v2_*.jsonl。
头显 ROBOT: UNKNOWN 仍属正常：尚未实现机器人状态回传。
通过离线测试不代表实机停止能力或5厘米行程已获验证。
